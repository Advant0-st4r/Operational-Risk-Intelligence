Purposes understood:

- create-case.command.ts — command to instantiate a new operational incident record with initial metadata and signals.  
- classify-severity.command.ts — command to attach/assign a severity (impact/urgency/overall) to a case.  
- identify-root-cause.command.ts — command to record or propose a root-cause hypothesis tied to evidence.  
- select-resolution.command.ts — command to choose and schedule a resolution action (owner, steps, ETA).  
- validate-resolution.command.ts — command to record validation results confirming whether the resolution succeeded.  
- capture-learning.command.ts — command to persist post-incident learnings, action items, and runbook updates.
